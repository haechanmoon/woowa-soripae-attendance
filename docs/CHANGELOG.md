# 업데이트 내역

소리패 시스템에 무엇이 언제 바뀌었는지 기록합니다. 배포할 때마다 한 줄씩 추가합니다.

정식 릴리스가 없는 연속 배포 방식이라 버전 번호 대신 **날짜**로 적습니다. 판단의 배경이 궁금하면 [decisions.md](decisions.md)를 보세요.

## 2026-08-06 · 지각비 정산 공지와 지난 날짜 출석 정리

**추가**
- 임원 관리에 **정산** 메뉴 추가. 지각비 미납부자 명단이 누적 벌금에서 자동으로 채워지고, 카카오톡 공지 문구를 만들어 **한 번에 복사**할 수 있습니다
- 계좌와 예금주만 입력하면 됩니다(기기에 저장돼 다음에 다시 치지 않아도 됩니다). 이번 정산용이라 행사명(하계공연)과 총무 이름(김유미)은 코드에 고정해 뒀습니다
- 이미 입금한 부원은 체크를 풀어 명단에서만 뺍니다. 출석 기록과 벌금 데이터는 그대로 둡니다

**고침**
- **대면 체크에서 지난 날짜를 고를 수 있습니다.** 그날 임원이 처리하지 못하고 넘어간 연습은 이후로 손댈 방법이 없어, 등록만 하고 기록이 비어 있는 부원이 실제로 남아 있었습니다 (8/5 조현근, 8/2 김도경). 정산 금액도 그만큼 비어 있었습니다
- 지난 날짜를 볼 때는 안내 문구를 눈에 띄게 바꾸고, 임원진 탭에 다시 들어오면 항상 오늘로 되돌아갑니다 — 오늘 것을 만지는 줄 알고 잘못 누르지 않도록

## 2026-07-27 · 스케줄 등록 현황과 접속 통계

**추가**
- 임원 화면의 등록 현황을 **이번 주 / 다음 주 토글**로 분리. 금요일부터 기본이 다음 주로 넘어갑니다
- 목록을 접고 **"등록 18/20"** 요약을 먼저 보여줍니다. 미등록자 색은 마감까지 남은 날에 따라 바뀝니다
- **마감 후 이번 주 스케줄 변경** — 사유를 적으면 즉시 반영되고, 임원이 나중에 사유를 보고 판단합니다
- 내 스케줄 목록에 **날짜 표시**를 추가하고 이번 주 / 다음 주를 나눴습니다. 전에는 둘 다 "수요일 13:00"으로 똑같이 보여서 본인이 이번 주 미등록인 걸 알 수가 없었습니다
- **접속 통계 페이지**(`/stats`) — 날짜별 접속자, 시간대별 이용량, 많이 열린 화면. 매시간 자동 갱신
- 로그인 화면 우측 상단에 통계 버튼

**개선**
- 대면 출석 명단의 "미등록"을 **"오늘 일정 없음"**으로 고치고 접어뒀습니다. 그날 일정이 없다는 뜻일 뿐인데 진짜 미등록자와 헷갈렸습니다
- 출석은 하루 한 번이면 인정되므로 연습 시간 관련 문구를 정리했습니다

**인프라**
- **테스트를 로컬 DB에서 분리** — `./gradlew test`가 로컬 MySQL에 마이그레이션을 적용하던 문제를 고쳤습니다 (인메모리 H2 사용)
- **봇 차단** — 스캐너 경로 차단 + IP당 속도 제한. 실사용자 영향이 없는지 동시 요청으로 검증했습니다

## 2026-07-26 · 출석 규칙 정비

- **출석을 하루 한 번 인증으로 변경.** 곡이 여러 개여도 한 번이면 그날 출석이 인정됩니다
- 종료 시각 제거 — 항상 "시작 + 2시간"으로 채워지던 값이라 실제와 맞지 않았습니다 (**V5 마이그레이션**, 중복 등록 정리로 운영 데이터 41건 → 34건)
- 지각 기준 시각을 서버가 결정합니다 (그날 등록 스케줄 > 없으면 코어타임 13시)
- **요일별 합주 현황** 추가 (이번 주 / 다음 주 토글)
- 주간 현황 인원을 연인원에서 고유 인원으로 수정 — 주 3회 오는 사람이 3명으로 세지고 있었습니다
- 오늘 등록했는데 아직 인증 안 한 부원 목록 추가

## 2026-07-24 · 운영 안정화

가장 많은 배포가 있었던 날입니다. 대부분 실제 사용 중에 드러난 문제를 고치는 작업이었습니다.

- **정적 파일 캐싱 문제 해결** — 브라우저가 옛 JS를 계속 잡고 있어 API 호출이 실패하던 문제. 경로 변경을 두 번이나 시도한 끝에 진짜 원인을 찾았습니다 ([자세히](decisions.md#광고-차단기-탓인-줄-알고-api-경로를-두-번-바꿨다))
- **날짜가 하루 밀리던 문제 해결** — 서버 타임존을 KST로 고정 ([자세히](decisions.md#날짜가-하루씩-밀렸다--타임존을-두-번-고쳤다))
- 인증 사진에 카메라 / 갤러리 선택 추가, 새로고침해도 사진 유지
- 임원 대면 체크에 다음 주 미등록자 현황 추가 (곡에 배정된 부원만 집계)
- 행사(공연) 등록 기능
- 임원 비밀번호 입력에서 모바일 확인키로 바로 인증
- 앱 이름을 **소리패 시스템**으로 변경, 등록 시간 기본값 13시 / 범위 08~23시
